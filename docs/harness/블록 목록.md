# 블록 목록

전체 흐름 탭을 실제로 만들 부품 목록이다. 다섯 종류로 나누고, 표마다 같은 칸을 쓴다.

- **단계**: 전체 흐름 탭의 단계 번호
- **사전**: [⛩️ harness is all you need](https://app.notion.com/p/4006ecddfa1c8185b979ffcf8dc2d5ac)에 이미 있는 브릭이면 그 이름, 없으면 "새로"
- **켜는 때**: 처음부터 / 반복되면 / 조건이 맞을 때

## 사전과 맞지 않는 곳

블록 사전에 옮길 때 고쳤야 할 곳이다. 1번은 위험 경로 블록으로 맞췄다.

1. **위험 경로가 흐름에 없었다.** 사전은 인증·결제·데이터 삭제 같은 위험 경로를 사람이 확인하는 걸 기둥으로 둔다(원칙 5, 6). → 5 잎 루프에 위험 경로 대기를 넣어 맞췄다
2. **다이얼이 두 개다.** 사전의 다이얼(L1\~L4)은 사람이 얼마나 보나이고, 범위 다이얼은 잎을 얼마나 넓게 고르나다. 옮길 때 "판단 다이얼"과 "범위 다이얼"로 나눈다
3. **재평가 횟수:** 사전은 고친 부분만 1번까지, 흐름은 FAIL 3번까지다. 새 세션이 지난 판정과 바뀐 부분만 보는 건 같고, 상한만 3으로 고친다
4. **올리기와 되돌리기:** 자동 머지는 머지 큐로, PR 되돌리기는 플래그 끄기로 먼저 바뀐다
5. **팀플 규칙:** "인터페이스를 바꿀 때는 담당자와 ADR부터"는 약속 바꾸기가 대신한다
6. **뼈대:** 사전 뼈대 목록에 트리 루프가 없다. 새 뼈대로 넣는다
